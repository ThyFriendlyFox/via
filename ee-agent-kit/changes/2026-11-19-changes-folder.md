### Added
- A change writes its changelog line into a file of its own, `ee-agent-kit/changes/<yyyy-mm-dd>-<slug>.md` (a heading such as `### Fixed`, then its `- ` lines), not into `CHANGELOG.md`, so 2 changes never write the same place: on 2026-11-19 `main` moved under an open pull request 5 times, and each time the pull request conflicted in `CHANGELOG.md` alone (M279). `python3 tools/ci/changes.py check` judges the files in the kit checks of `make verify` and `make verify-site`; `show` prints what `## [Unreleased]` holds from both places; a release runs `fold <X.Y.Z> <date>`, which writes the release's section and deletes the files. A line written straight under `## [Unreleased]` stays valid.
