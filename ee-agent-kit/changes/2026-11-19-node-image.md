### Changed
- The container image holds node, Ubuntu 24.04's `nodejs` (18.19.1), so CI's whole suite runs inside it: the 3 test files that run node no longer skip there (CI runs 44409635104 and 44428908528 skipped them with `'node is not on PATH'`). `tools/image.py decide` loses its node rule, which sent a change to the forms' functions, the lead's workflow scripts, the nightly's issue step or their tests to the install path (on 2026-11-19 a push of website work took it for that alone and stopped at the download's bound on both attempts, CI run 44432768560). `image.py record` refuses an image without node, and `image.py show` and `workcenter image` print its version. `workcenter doctor` names node as a tool of Via's own tests; absent, it degrades nothing, since a board needs none. install.sh does not install it. The forms' test driver gives node 18 the global `crypto` it lacks. The Dockerfile changes the content tag, so CI takes the install path until the `Image` workflow on main has published the new tag.
