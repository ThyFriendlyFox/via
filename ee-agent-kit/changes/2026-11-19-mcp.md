### Added
- `workcenter mcp [ROOT]`: an MCP server on stdio (revision 2025-11-25) for hosts that are not Claude Code. Its 7 tools, `doctor`, `gates`, `erc`, `drc`, `sim`, `export` and `autoroute`, run their commands and answer their lines and exit codes. A path outside ROOT is refused; `ping` and a cancel are answered while a gate runs. A path with a NUL byte is refused in 1 line; a count of 3.0 is taken as 3 (JSON Schema 2020-12 validation, 6.1.1 `type`); a cancelled call sends no further progress. The `mcp` skill.
