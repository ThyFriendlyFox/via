### Changed
- CI's install path and the nightly run keep more than 1 host for Ubuntu's archive and ask the fastest first (`tools/ci/apt_archive.sh`). The mirror list keeps the runner's mirror, archive.ubuntu.com and security.ubuntu.com; a probe of at most 5 s asks each for the first 1 MiB of an index and sets their priorities by bytes a second; a host that does not answer goes last and stays. A CI-only file, `/etc/apt/apt.conf.d/80apt-archive-ci`, sets a 15 s timeout and no retry on the same host, so a file whose host is silent goes to the next host at once. Before, the step turned the runner's mirror into archive.ubuntu.com and left apt 1 host: in CI run 44477966021 (2026-11-19, 07:14 UTC) archive.ubuntu.com did not deliver the index within 120 s in 3 tries. The step prints 1 line per host with what it measured, and the order it chose; where priorities tie, it says apt picks at random. A person's computer, install.sh and the image build are not changed; `CI_APT_UBUNTU_ARCHIVE=0` still turns the step off.
