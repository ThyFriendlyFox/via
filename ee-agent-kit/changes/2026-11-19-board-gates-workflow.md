### Added
- A board repository gets `workcenter gates` on every pull request from 1 workflow that calls `ThyFriendlyFox/via/.github/workflows/board-gates.yml@main` (the `board-ci` skill). Each project folder is 1 job; its summary holds the gates table and where the gates ran; RED and SKIPPED are red checks, and so is a GREEN with no board to judge (ERC, DRC or EXPORT at skip). Nothing is posted to the pull request. It runs in Via's public image; where the registry holds no image of that toolchain, it installs with install.sh after ranking the hosts of Ubuntu's archive, as CI's install path does.
