### Changed
- CI's install path and the nightly run keep apt's package files between runs, so a run asks the package hosts only for what changed (`tools/ci/apt_cache.sh`); on GitHub a run with the files kept fetched 0 B of 281 MB. A push to main, the nightly run and a run by hand save; a pull request only restores. apt takes a file already in its folder by its size alone, so after the install every file is checked against the SHA256 of apt's signed indexes, and a mismatch fails the run. The `full` job's limit is 45 minutes.
